How every number is made

Implied value = 10^(intercept + slope × log10(TVL) + category offset) × growth × maturity × breadth. The comps curve is fitted at run time from the live protocols in this snapshot — an OLS line of log10(market cap) on log10(TVL), slope shrunk by half, plus a per-category offset. No protocol name is ever special-cased.

Integrity strip — six proofs that can fail

Every proof below is recomputed from the data on this page. A proof that fails shows FAIL in red — nothing here is a claim you have to take on trust.

Token odds — what they are and are not

Token odds are the observed share of protocols in the same age band that already record a token (a market cap, a Gecko id or a symbol), smoothed toward the global base rate. They are a base rate from the peers' record, not a prediction: a token may never be issued, and the odds never say it will. Age unknown uses the global base rate and says so.

Model sandbox

Move a slider and the selected protocol's implied value is recomputed with the same formula. The board itself is fixed by the snapshot; the sandbox only shows how sensitive it is.

What the radar does not claim

Implied value is a model estimate, never a price and never a prediction of whether or when a token is issued. A token may never be issued. A protocol is shown as recording no token, never as having none — its DefiLlama record may simply not carry one. Wrapped, staked and bridged products of tokens that already trade are excluded, as are exchanges and versioned pools.
